One picture of food, made to be eaten with the eyes first: an
Indonesian nasi campur feast on a banana leaf — glossy beef rendang,
golden turmeric rice, red sambal and green sambal ijo, a lacy-edged
fried egg with a bright yolk, prawn crackers, cucumber and a shower of
crispy shallots. Colour, gloss and texture in every quadrant, and the
whole plate still reads at thumbnail size.

The picture was generated and finished by the agent for this bounty.
main.py is the entrypoint the grader runs: it copies the committed
entry.png to /output/entry.png, byte for byte, on every run. MIT
licensed; see LICENSE.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
